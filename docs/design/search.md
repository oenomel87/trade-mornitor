# 종목 검색

2단계의 첫 기능이다. [랭킹](./rank.md)과 [관심종목 관리](./watchlist.md)도 구현되었다.

```sh
tmon search 삼성전자
tmon search 현대자동차 --market KR
tmon search AAPL --market US
tmon search apple --json
tmon search 반도체 --market KOSPI --limit 50
tmon search 현대차 --refresh
```

## 계약

- 위치 인수 `QUERY` 하나, 공백만 있는 검색어는 로컬 오류다. 띄어쓰기가 있으면 따옴표로 감싼다.
- `--market`: 기본 `ALL`. `KR`, `US` 또는 KOSPI·KOSDAQ·KR_ETC·NYSE·NASDAQ·AMEX·US_ETC.
- `--limit`: 기본 20, 1~200. 출력 개수만 제한하며 전체 일치 개수는 메타데이터로 제공한다.
- `--refresh`: 유효한 캐시도 API에서 다시 받는다. 강제 갱신 실패 시 과거 캐시로 성공 처리하지 않는다.
- `--json`과 `--no-color`: 기존 명령과 동일하다.
- 대상은 `GET /api/v1/stocks/all?market=...&status=ACTIVE`로 받은 토스증권 거래 가능 목록이다. 종목 유형은 제한하지 않는다.
- 검색 결과 필드: `symbol`, `name`, `market`, `securityType`, `isCommonShare`.
- 대소문자·유니코드 표현·공백 차이를 정규화하고 코드와 한글명 부분 일치를 지원한다.
- 정렬: 코드·이름 완전 일치 → 명시적 별칭 일치 → 접두 일치 → 부분 일치. 동순위는 이름·시장·코드 순이다.
- 전체 영문 회사명 데이터는 제공되지 않는다. 초기 별칭은 `apple→AAPL`, `현대자동차/hyundai motor→005380`, `samsung electronics→005930`이며 해당 실제 코드가 목록에 있을 때만 결과를 낸다.
- 0건은 `status=ok`, `data=[]`, 종료 코드 0이다. API 실패로 목록을 확보하지 못한 상태와 구분한다.
- 검색은 분석·조회 명령을 자동 실행하지 않는다. 표시된 코드를 `quote`, `history`, `analyze`에 전달한다.

## 캐시와 장애

- 사용자 캐시 디렉터리의 `stocks-v1/<market>.json`에 시장별 목록과 수집 시각을 저장한다. 유효기간은 수집 후 24시간이다.
- 유효한 캐시만으로 검색할 때는 인증 정보와 네트워크가 필요 없다.
- 갱신은 프로세스 간 파일 잠금 후 캐시를 다시 확인한다. 응답 검증 후 원자적으로 저장한다.
- 누락·형식 오류·버전 불일치·만료 캐시는 갱신 대상이다.
- 일반 검색의 만료 캐시 갱신이 네트워크·서버·호출 제한 오류로 실패하면 기존 목록을 사용하되, 시장과 시각을 표시하고 `status=partial`, 종료 코드 5로 반환한다.
- 캐시도 없거나 인증·데이터 오류 또는 강제 갱신이 실패하면 명령을 실패시킨다. 일부 시장만 검색해 전체 결과처럼 표시하지 않는다.
- `meta`에 검색어, 선택 시장, 일치·출력 개수, 잘림 여부, 시장별 수집 시각·캐시 사용·만료 여부를 포함한다.
- 종목 목록은 시장별 초당 1회 제한을 고려해 순차 조회한다. 기존 응답 헤더 및 전체 60초 예산도 적용한다.

## 검증

이름·코드·별칭·유니코드·정렬·시장 선택, 0건과 출력 제한, 24시간 경계·캐시 손상·강제 갱신·실패 시 과거 캐시 표시, 오프라인 재사용과 프로세스 간 갱신 잠금을 검증한다. 실제 삼성전자·현대차·애플 검색 및 반환 코드의 조회 연결도 확인한다.

근거: [종목 정보 API](https://developers.tossinvest.com/docs/stock-info).
