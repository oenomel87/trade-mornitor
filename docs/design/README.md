# 주가 조회·분석 CLI 설계

작성일: 2026-09-05 · 상태: 조회·관심종목 및 국내 단기매매 후보 추천 첫 구현 완료, 추천 장중 검증 대기

## 목표

터미널에서 국내·미국 주식의 가격과 과거 데이터를 조회하고, 계산 근거가 보이는 기본 분석을 수행한다. 작은 CLI로 시작해 실제 사용에 필요한 기능을 단계적으로 추가한다.

설계를 바탕으로 1단계 조회·분석 CLI를 구현했다. [사용법](../../README.md)과 [검증 기록](../implementation-verification.md)을 참고한다. 계좌·매매 기능은 포함하지 않는다.

## 확정한 방향

- 매매는 하지 않는다. 주문 생성·정정·취소와 조건주문은 구현 범위에서 제외한다.
- 사용 인터페이스는 CLI다. 웹 화면과 상시 실행 서버는 첫 버전에 포함하지 않는다.
- 첫 버전은 요청할 때 데이터를 가져와 결과를 출력하고 종료한다.
- 국내·미국 종목을 심볼로 지정한다. 예: `005930`, `AAPL`.
- 인증 정보는 기존 `TOSS_CLIENT_ID`, `TOSS_CLIENT_SECRET` 환경 변수를 사용한다.
- 기존 `analyze`는 관측값과 계산 결과를 설명한다. 후속 `recommend`는 사용자와 합의한 범위에 따라 국내 단기매매 후보와 진입·무효화 조건을 제시한다. 전략 조건 충족을 승률로 표시하지 않는다.
- 사람이 읽는 표를 기본으로 하고, 자동화용 JSON 출력을 함께 설계한다.

## 첫 버전 범위

| 기능 | 제공 결과 | 범위 |
| --- | --- | --- |
| 연결 진단 | 환경 변수 존재 여부, 로컬 설정 상태, 선택적 API 연결 확인 | 비밀값 출력 금지 |
| 현재가 조회 | 심볼, 현재가, 통화, 시세 시각 | 최대 200종목, 한 번 조회 |
| 일봉 조회 | 시가·고가·저가·종가·거래량 | 종목 하나, 완료된 일봉 최대 200개 |
| 기본 분석 | 종가 변화율, SMA20·60, RSI14, 거래량 배수 | 완료된 수정주가 일봉 기준 |

명령 이름은 `tmon`으로 확정했다. 설치 없이 `./bin/tmon` 또는 `python3 -m tmon`으로 실행한다.

## 후속 구현 범위

- [국내 단기매매 후보 추천](./recommend.md)의 정량 선별·분봉·호가·Codex 웹 조사·실행 기록은 구현했다. 토스 제공 시세 기준으로 NXT 지원 종목을 포함하며, 장중 지연과 데이터 집계의 일관성을 실제 운영으로 검증한다.
- 웹소켓, 반복 감시, 알림 및 예약 실행
- [시황·뉴스 브리핑](../brief.md)은 구현했다. 국내 지수·KRX 투자자별 매매대금·랭킹과 Codex SDK 뉴스를 결합하며 예약 실행과 알림 전송은 별도로 연결한다.
- 전 종목 스크리닝, 관심종목 묶음 분석 (검색·랭킹·프로필별 관심종목 저장·묶음 현재가는 구현 완료)
- 분봉과 다중 시간 단위 분석
- 종목별 투자자 수급, 공매도·신용·대차 분석 (브리핑의 KRX 시장별 수급은 구현 완료)
- 계좌·보유자산 조회
- 로컬 시세 DB, 대량 과거 수집, 백테스트
- 뉴스·공시·재무 데이터, AI 설명 생성

계좌 조회는 향후 조회 전용 확장 후보이며 초기 인증 확인에 사용하지 않는다. 매매 기능은 확장 계획에도 포함하지 않는다.

## 문서로 확인한 API와 검증이 필요한 부분

아래 사실은 2026-09-05 공식 문서를 열람한 결과다. 현재가·일봉·캘린더와 인증은 실제 API에서도 확인했으며, 남은 검증 한계는 별도 기록에 명시했다.

| 항목 | 문서에서 확인한 내용 | 설계 영향 |
| --- | --- | --- |
| 인증 | Client Credentials, 재발급 시 기존 토큰 무효화 | 캐시와 프로세스 간 발급 잠금 필요 |
| 접속 | 허용 IP 등록 필요 | 인증값 외에 실행 환경의 IP도 확인 |
| 현재가 | 한 번에 최대 200종목 | 첫 버전에서 자동 분할 호출 제외 |
| 캔들 | 1분봉·일봉, 최대 200봉, 수정주가, `nextBefore` | 첫 버전은 일봉과 제한된 추가 조회만 사용 |
| 시장 일정 | 국내·미국 장 운영 정보 | 미완성 일봉 제외 기준에 활용 |
| 호출 제한 | API 그룹별 제한, 응답 헤더로 현행 한도 제공 | 한도 숫자를 고정 가정하지 않음 |

지속 확인할 데이터 조건:

- 일봉 timestamp의 의미, 정렬·중복, 거래 세션 범위, 당일 봉의 확정 시점
- 캔들 페이지 경계와 `nextBefore` 종료 조건
- 수정주가에 반영되는 기업행사와 거래량 조정 방식
- 휴장일·시간외 시장의 현재가 시각 및 일봉 처리
- 여러 심볼 중 일부가 잘못된 현재가 요청은 실응답에서 정상 종목만 반환됨을 확인했으며, 누락 종목을 표시한다.
- 시장 캘린더의 조회 범위와 일봉 확정 판단에 충분한 정보 제공 여부

확인 전에는 최근 봉이 확정됐다고 가정하거나, 수정주가 수익률을 배당 포함 총수익률로 표기하지 않는다.
