상태: PR0·PR1 원본 반영 완료 · PR2 재작업 중 제공자 호출 제한으로 중단 · 시작일: 2026-09-08 (Asia/Seoul)

명세: [최종 수정 작업 명세](./recommend-snapshot-v2-work-spec.md)

## 역할과 실행 원칙

- Codex: 설계·작업 분해·구현 지시·독립 코드 검토·테스트 실행·통합·이력 기록.
- OpenCode auto: 제품 코드·테스트 구현 및 검증 피드백에 따른 수정.
- 기존 미커밋 변경을 포함한 격리 작업 사본에서 구현한다. 원본과 기준 해시를 비교한 뒤 검증된 변경만 반영한다.
- 자동 push·배포·주문·실거래 API 검증은 구현 작업에 포함하지 않는다. 구현 프로세스에 토스 인증 환경변수를 전달하지 않는다.
- PR1·PR2·PR3 인터페이스를 먼저 설계하고 PR0부터 순차 구현·검증한다. 후속 체결·성과·저장소·v2 전략 실험은 구현하지 않는다.
- 오류·검증 실패·재작업도 기록한다. 실제 테스트 실행과 정적 판단, 공급자 정책의 미확인을 구분한다.

## 2026-09-08 — PR0 실행 시도와 차단

- 준비된 실행: `opencode run --auto --format json`에 모델 `EXTERNAL_MODEL_REDACTED`, 격리 작업 경로, PR0 한정 지시서를 명시.
- 지시 범위: 전체 screened 스냅샷·중복 종목 조회 제거·요청 및 재시도 관측·근거 기반 오류 분류·관련 테스트·문서. 명세 전체를 한 번에 구현하지 않도록 제한.
- 구현용 실행 환경은 PATH·HOME·로케일·임시 디렉터리 등 필요한 기본 값만 전달하고 토스 인증 환경변수는 전달하지 않도록 준비.
- 자동 승인 검토 결과: **실행 거부**. 저장소 내용이 명시적으로 승인되지 않은 Fireworks 모델로 전송될 수 있다는 외부 반출 위험을 사유로 제시.
- 프로세스 생성 단계에서 차단됐으므로 OpenCode 세션 ID·모델 응답·구현 diff는 없음. 인증·모델 연결 성공으로 기록하지 않음.
- 우회 실행이나 다른 제공자로의 임의 전환은 수행하지 않음. 필요한 추가 승인: 해당 Fireworks 모델에 구현에 필요한 저장소 코드·문서를 전송해 작업하도록 허용.
- 제품 코드와 테스트는 수정하지 않았으며 기존 작업 트리는 보존. 이번 추가 산출물은 작업 로그·인터페이스 설계·설계 목차 링크다.
- 재개 절차: 제공자 전송 승인 확인 → 격리 사본과 원본의 기준 해시 재확인 → 준비된 PR0 실행 → 독립 검증 → 다음 단계.
