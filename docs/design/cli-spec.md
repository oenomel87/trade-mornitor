# CLI 기능과 출력 규칙

상위 문서: [설계 개요](./README.md)

아래 인터페이스는 1단계 CLI에 구현되었다. 워크스페이스에서는 `tmon` 대신 `./bin/tmon` 또는 `python3 -m tmon`을 사용한다.

2단계에서 추가한 명령은 [종목 검색](./search.md), [랭킹](./rank.md), [관심종목](./watchlist.md), [프로필](./watchlist-profiles.md) 명세를 따른다. 공통 JSON 출력 계약은 동일하다.

## 공통 규칙

- 명령 구조: `tmon <command> [arguments] [options]`
- `--help`: 사용법과 옵션 설명. 네트워크·인증 없이 동작한다.
- `--json`: 표 대신 버전이 있는 JSON 객체를 출력한다.
- `--no-color`: ANSI 색상을 끈다. 파이프로 전달할 때도 자동으로 끈다.
- 종목코드는 문자열로 다룬다. `005930`의 앞자리 0을 보존하고 영문 티커는 대문자로 정규화한다.
- 통화를 함께 표시하며 첫 버전에서 원화·달러를 자동 환산하지 않는다.
- 시각은 UTC 오프셋이 포함된 ISO 8601로 제공하고, 일봉 날짜는 해당 시장의 거래일로 해석한다.
- 입력 검증을 인증·네트워크 호출보다 먼저 수행한다.

## 1. `doctor`: 로컬 설정과 연결 진단

```sh
tmon doctor
tmon doctor --remote
tmon doctor --remote --json
```

기본 실행은 환경 변수의 존재·공백 여부, 토큰 캐시 디렉터리 접근 가능 여부만 검사한다. 값, 길이, 토큰 일부는 출력하지 않는다.

`--remote`는 캐시 토큰을 재사용하거나 필요할 때 발급하고, `GET /api/v1/prices?symbols=005930`으로 시장 데이터 접근을 확인한다. 계좌 API는 호출하지 않는다. 도움말에 새 토큰 발급이 기존 토큰을 무효화할 수 있음을 명시한다.

결과는 `설정됨 / 누락 / 정상 / 실패 / 미확인`으로 구분한다. 403을 IP 문제로 단정하지 않고 API 에러 코드와 함께 허용 IP·권한 확인을 안내한다. 로컬 진단 성공은 API 연결 성공을 뜻하지 않는다.

## 2. `quote`: 현재가 조회

```sh
tmon quote 005930
tmon quote 005930 AAPL MSFT --json
```

- 필수 입력: 심볼 1~200개. 중복 제거 후 200개 초과 시 로컬 오류로 종료한다.
- API: `GET /api/v1/prices`.
- 출력: 심볼, 현재가, 통화, API 시세 시각, 조회 시각.
- 응답 순서와 관계없이 요청한 심볼 순서로 정렬한다.
- 현재가 응답만으로 알 수 없는 전일 대비 등락률이나 종목명은 첫 버전에 추가하지 않는다.
- 일부 심볼이 반환되지 않으면 누락 심볼을 명시하고 부분 결과로 처리한다. 서버가 요청 전체를 거부하면 임의로 종목별 재시도하지 않는다.
- 시세 시각을 항상 표시한다. 장 마감 후 오래된 시세라는 이유만으로 오류로 처리하지 않는다.

## 3. `history`: 완료된 일봉 조회

```sh
tmon history 005930
tmon history AAPL --count 60 --json
tmon history 005930 --count 20 --unadjusted
```

- 입력: 심볼 하나, `--count` 1~200(기본 20).
- API: `GET /api/v1/candles`, `interval=1d`.
- 수정주가를 기본으로 사용하고, `--unadjusted`일 때만 미적용한다.
- 출력: 거래일, OHLCV, 통화, 수정주가 적용 여부, 최종 데이터 시점.
- 결과는 과거→최근 순으로 정렬하며 완료된 봉만 출력한다.
- 최근 봉 제외로 요청 개수가 부족하면 `nextBefore`로 추가 조회한다. 첫 버전은 전체 최대 3페이지로 제한한다.
- 추가 페이지가 없거나 제한에 도달하면 확보한 데이터와 부족 경고를 출력한다. 빈 날짜를 인위적인 봉으로 채우지 않는다.
- 같은 timestamp의 중복 봉은 내용이 같으면 합치고, 값이 다르면 데이터 오류로 처리한다.

첫 버전은 날짜 범위 지정과 무제한 페이지 수집을 지원하지 않는다. 봉 확정 판단은 [구조 문서의 데이터 기준](./architecture-and-roadmap.md#데이터-기준)을 따른다.

## 4. `analyze`: 기본 기술적 분석

```sh
tmon analyze 005930
tmon analyze AAPL --json
```

완료된 수정주가 일봉 120개를 목표로 확보한다. `history`와 동일한 정규화·페이지 제한을 사용한다. 필요한 봉이 부족한 지표만 `N/A`로 표시하고, 나머지는 계산한다. 120봉은 초기화 목표이며 지표를 하나 이상 계산할 수 있으면 이력이 짧아도 종료 코드 0과 `status=partial`을 반환한다.

| 결과 | 정의 | 최소 데이터 |
| --- | --- | --- |
| 종가 변화율 | `(최근 종가 / 직전 종가 - 1) × 100` | 2봉 |
| SMA20·SMA60 | 최근 20·60개 종가의 산술평균 | 20·60봉 |
| SMA 대비 괴리율 | `(최근 종가 / SMA - 1) × 100` | 해당 SMA와 동일 |
| RSI14 | Wilder 방식, 아래 초기화 규칙 적용 | 15봉 |
| 거래량 배수 | `최근 봉 거래량 / 직전 20봉 평균 거래량` | 21봉 |

RSI는 첫 14개 가격 변화의 상승·하락 평균으로 초기화하고, 이후 `(이전 평균 × 13 + 현재 값) / 14`로 갱신한다. 하락 평균만 0이면 100, 상승 평균만 0이면 0, 둘 다 0이면 50으로 정의한다. 계산 시작점의 영향을 설명할 수 있도록 실제 사용 봉 수와 기간을 출력한다.

분모가 0인 변화율·괴리율·거래량 배수는 `null`과 사유를 반환한다. 값이 없는 데이터를 0으로 대체하지 않는다.

출력은 기준 거래일·통화·사용 기간·봉 수·수정주가 적용 여부와 지표값을 포함한다. 해석 문구는 “종가가 SMA20 위에 있음”, “직전 20봉 평균 대비 거래량 1.8배”처럼 값에서 직접 확인되는 사실만 제공한다. 단일 시점의 상회 상태를 ‘돌파’로 표현하지 않는다.

## 출력 계약

일반 출력은 간결한 표와 필요한 경고로 구성한다. JSON은 다음 공통 필드를 갖는다.

| 필드 | 의미 |
| --- | --- |
| `schemaVersion` | 초기 값 `1`, 출력 계약 버전 |
| `command` | 실행한 명령 |
| `status` | `ok`, `partial`, `error` |
| `data` | 명령별 결과, 실패 시 `null` |
| `meta` | 조회 시각, 데이터 기준 시각·기간, 출처, 사용 봉 수 등 |
| `warnings` | 코드와 설명의 배열, 없으면 빈 배열 |
| `error` | 오류 코드·설명·재시도 가능 여부·공급자 요청 ID, 정상 시 `null` |

가격·수량·계산 결과는 JSON에서 십진 문자열로 표현한다. 개수·버전은 정수, 결측값은 `null`이다. 변화율은 퍼센트 단위(`1.25`는 1.25%)이며 필드명에 `Pct`, 거래량 배수에는 `Ratio`를 사용한다. 내부 계산 정밀도를 유지하고 출력 시 소수점 8자리까지 반올림한다. 로컬 진단 오류 시 항목별 결과는 `meta.checks`에 보존한다.

JSON 모드는 오류를 포함해 stdout에 JSON 객체 하나만 출력한다. 진단 로그는 stderr로 분리하며 인증값·인증 헤더는 기록하지 않는다. 일반 모드는 결과를 stdout, 오류·경고를 stderr로 출력한다.

| 종료 코드 | 의미 |
| --- | --- |
| 0 | 명령 성공. 일부 지표 계산 불가는 경고로 안내 가능 |
| 1 | 예상하지 못한 내부 오류 |
| 2 | 입력 또는 로컬 설정 오류 |
| 3 | 인증·접근 권한 오류 |
| 4 | 네트워크·호출 제한·공급자 장애 |
| 5 | 종목 없음, 데이터 오류·없음, 요청 종목·봉 수의 부분 결과 |

분석에서 지표 일부가 `N/A`이면 `status=partial`과 종료 코드 0을 사용한다. 계산 가능한 지표가 하나도 없으면 종료 코드 5다. 오류 원문 전체나 HTTP 요청·응답을 그대로 덤프하지 않는다.

## 첫 버전 완료 기준

- 네 명령의 도움말과 로컬 입력 오류가 네트워크 없이 동작한다.
- 국내·미국 종목 각 하나에서 시각·통화·봉 정렬·수정주가 설정을 확인한다.
- 미완성 봉이 분석에 섞이지 않으며 확정 여부가 불명확하면 그 사실을 표시한다.
- 수기로 검산 가능한 고정 데이터로 SMA·RSI·거래량 배수와 결측·0분모 처리를 검증한다.
- 토큰 캐시 재사용, 동시 발급 방지, 제한된 재시도와 429 처리를 검증한다.
- JSON이 파싱 가능하고 일반 출력과 동일한 값을 제공한다.
- 비밀값이 출력·로그·저장소에 남지 않고 주문 API를 호출하는 경로가 없다.
